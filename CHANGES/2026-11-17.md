# Week of November 17, 2026

19 changes to the app this week.

## New

- **Bins:** The bin pop-up's lower half goes behind tabs
- **Bins:** A bin opens on its movements

## Changed

- **Forms:** Acres cannot be negative, and the database says so too

## Fixed

- **Audit:** The other four tables, and only what a person did
- **Bins:** The bin pop-up's buttons stop spreading over three rows
- **Bins:** The bin map is turned away, and moisture typed as humidity is caught
- **Bins:** Bin readings are audited again, and the undo tool starts
- **Demo:** A browser without WebAssembly is told what is wrong, before the download
- **Planner:** A goal in the wrong unit is not a grade, and a split field is one field
- **Scale:** The weigh-in form no longer promises a time it will not save
- **Scale:** No weigh-out time where there was no second weighing

## Other changes

- Say what the database said, instead of [object Object]
- Say when a split field's zones do not add up
- Hold the plan's export and the budget's to the same totals
- Say how current a budget price or input cost is
- Say what an inline crop change did
- Open a budget total and see the fields under it
- Stop [object Object] coming back
- Keep a filter you use often under a name

## Bringing this into your copy

This release has a file called `changes-2026-11-17.patch` holding just this
week's code. Download it and give it to your AI assistant with something like:

> Here is this week's patch from the Farm Management System. Apply it to
> my app. Where it touches something I have changed, keep my version's
> behaviour and tell me what you did. If it adds anything to
> `supabase/migrations`, tell me what to run on my database.

Or, if you have not changed much, pull the whole repository again.

In Claude Code there is nothing to download: run `/update` in the project
folder and it checks for this release itself, says what changed, and asks
before it touches anything.
