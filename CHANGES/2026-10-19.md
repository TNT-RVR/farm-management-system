# Week of October 19, 2026

35 changes to the app this week.

_Corrected 23 October 2026: the first version of these notes listed only 3 changes, all of them already in the first public copy. The code in this release was complete; only the notes were short._

## Changed

- **Bell opens a notifications dropdown:** Read circles, kind labels, expand and settings
- **Bins:** Totals in kilograms and tonnes beside bushels, and each field's weighed kg, bushels and tonnes (seed companies ask for kg)
- **Calculator:** Operation cost and Irrigation cost tabs
- **Combine:** Monitor files tab (boundary shapefiles, field names, display record, out-of-date alert)
- **Combine:** John Deere guidance lines on the combine stick (MultiSwath+)
- **Combine:** "Start a field" checklist on Starting settings
- **Combine monitor:** Per-crop "Harvested with the combines" switch drives the fields
- **Combine monitor:** Grower, Farm and Field per field
- **Combine monitor names:** Join a quarter to its legal land as the last shortening step
- **Combines:** Conditions & suggested adjustments card (NDVI thickness, grain moisture, field weather -> rule-based starting changes)
- **Combines:** Field finished record, loss checks keep the settings and conditions, What worked
- **Combines:** Save to USB stick writes the files straight onto the stick; ISOXML TASKDATA beside the shapefiles; Reports search box
- **Dry down chart:** A line at today (by day) and this hour (by hour)
- **Field names are file safe:** No / \ : * ? " < > | (fractions as words, separators as -); the field page blocks them, imports and the database clean them
- **My account:** Connected apps merged into This device; sections use the width on a desktop (two columns where there are two cards)
- **Not a normal year:** Mark a harvest so averages leave it out; flag estimates from a crop default
- **Notifications:** A switch for every kind, in the app and push; Alerts page renamed
- **Notifications:** Clearer names for every kind and a one-line explanation under each switch
- **Notifications:** Quiet hours and a daily digest for pushes
- **Power bills:** Azgard on the QuickBooks reader; an Azgard PDF never doubles the account page's rows
- **Profile pictures:** Upload your own, faces of who else is in the app top right, assignee circles on tasks; setup checklist items open the exact spot; drop Farm setup's Connections part
- **Profile pictures:** Let people see their own avatar files so the upload isn't refused by RLS
- **Profile pictures:** Fit the photo in the circle (drag, zoom slider, wheel, pinch) and Adjust it later from the kept original
- **Public copy:** Combines > Monitor files asks for the farm's combine and gives an AI-assistant prompt to build its exporter
- **Reports:** Season wrap-up, a page a field for the bank, insurance and next year's plan
- **Service reminders from engine hours:** Due tasks after every Deere sync, done rolls the plan on
- **Start a field:** Any active user can save the settings they ran; managers keep the defaults
- **Weekly public copy:** Farm-clock test uses 2025's clock changes (tz 2026c keeps Alberta on daylight time from Nov 2026, so 2026 dates differ between Node versions); two copy-only tests left out

## Fixed

- **Any.do sync:** Stop writing Any.do's id into tasks.source_ref (a uuid), which failed every 10 minutes; the id stays on anydo_task_links
- **Operation cost calculator:** Repair garbled dashes and ellipses (text was saved as Windows-1252 twice)

## Other changes

- Conference room TV button moves from the header to the Monday meeting page, beside Print
- What's missing checklist (/missing + Monday meeting card); harvest coming and yield vs estimate on the meeting
- Row rules check is_active()/is_manager() once per query, not per row: 414 policies wrapped; plc_line_integrity 8.75 s -> 0.13 s (it was timing out for signed-in users)
- Fixer-stuck alert and stalled engine hours
- Prescriptions show the linked field's current name (renamed fields read the same everywhere); the Rx's printed label still keys re-imports
